# claude-skills

Custom Claude skills.

| Skill | Purpose |
|---|---|
| [grill-me](grill-me/SKILL.md) | Interview relentlessly about a concept, design, or open decisions until understanding is shared |
| [multiphase-pr-review](multiphase-pr-review/SKILL.md) | Phased PR review: scope, architecture, code quality, validation |
| [pr-split](pr-split/SKILL.md) | Split a large branch or PR into smaller draft PRs, stacked or targeting main |
| [publish-pr](publish-pr/SKILL.md) | Publish a draft PR with a ticket-key title and New/Old Behavior description |
| [ship-review](ship-review/SKILL.md) | Post review findings as a GitHub PR review |
| [take-feedback](take-feedback/SKILL.md) | Triage PR review comments with 👍/👎 reactions and drafted replies |
| [thermo-nuclear-code-quality-review](thermo-nuclear-code-quality-review/SKILL.md) | Extremely strict maintainability review |
| [ticketed](ticketed/SKILL.md) | Create Jira tickets in the current sprint with Background + Acceptance criteria |
